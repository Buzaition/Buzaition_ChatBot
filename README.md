# Buzaition Bot AI Chatbot

Simple AI chatbot website powered by the Google Gemini API.

Built with:
- Vanilla JavaScript
- Node.js
- Google Gemini API
- Modern responsive UI
- Multi-chat history system
- Local storage persistence
- Multiple API key fallback support

---

# Features

- Modern chatbot-style interface ☺
- Multiple chat conversations
- Chat history sidebar
- Responsive design
- Markdown-like AI responses
- Copy messages
- Edit user messages
- Delete messages
- Auto-resizing textarea
- Theme switching
- AI typing/thinking states
- Gemini API integration
- Multiple Gemini API keys support
- Automatic fallback between API keys
- Secure backend API handling
- Ready for Vercel deployment
